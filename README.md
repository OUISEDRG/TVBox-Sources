## 首批审核
2026-11-25 已读取五组候选配置，均未确认内容授权及依赖安全。qist 与高天流云 README 限制使用/转载并不保证合法性；肥猫、王二小、饭太硬为镜像，不能证明原内容授权。当前 0 个通过正式审核，禁止导入整包。根据用户后续确认，少量固定版本站点可在候选入口试用，明确标注未经审核；不自动进入正式入口。最新统计见 reports/health.json，来源见 config/upstreams.json。
首批真机反馈：量子（电视剧/电影）、赏月动漫、稀饭动漫、红果短剧、七猫短剧均正常；金蝉播放失败，人工隔离且须用户重测才能恢复。播放正常的站点使用 trial_verified 状态，保持原接口及固定依赖版本；未验证的新站点排序在其后。根据用户要求，从已实测正常的站点中设置四类试用主力；未测候选不参与主力排序。依赖来自 qist/tvbox 固定提交，未在 CI 执行、未安全审查、未确认内容授权。用户反馈仅代表其测试环境中的播放结果。请仅播放有权观看的内容。第三方代码有风险，建议使用隔离测试环境，不输入个人账号或敏感信息。

## 真机验收与正式上线
候选进入 preview 后：用户用 FongMi 检查首页、搜索、详情、实际播放、拖动和切集，提供站点名称/版本/结果/时间及主力选择。维护者确认授权、安全、兼容记录和人工评分（80+）后，将该站点 approved/playback_verified 设为 true、状态 active，运行 build/check 并提交。已收到三批播放反馈，单独存入 registry.json 和 reports/health.json，不等同于全部验收、授权或安全通过。未经反馈不得提前发布。背景为暖米白图片；全局主题、海报比例须客户端验证。

详见 AGENTS.md。运行：`python3 scripts/test.py`，`python3 scripts/sync.py --check`。
